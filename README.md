# 🎓 LearnSense AI – Intelligent Learning & Assessment Platform

**Learn smarter. Teach better. Grow together.**

LearnSense AI is an AI-powered personalised learning and assessment platform designed to improve communication between teachers and students while making education more intelligent, interactive, and data-driven.

The platform helps teachers identify students' learning gaps, generate assessments from uploaded study materials, analyse academic performance, and provide personalised learning recommendations.

## 🚀 Project Overview

Traditional classroom environments make it difficult for teachers to identify every student's individual learning challenges.

LearnSense AI addresses this problem using Artificial Intelligence to analyse student performance, identify weak concepts, and recommend personalised learning activities.

It creates a connected learning environment where teachers can manage learning materials, students can complete assessments, and both can monitor academic progress.

## 🔄 How It Works

1. Teacher uploads study materials (PDF/notes).
2. AI extracts important concepts.
3. AI generates questions and assessments.
4. Students attend online assessments.
5. AI evaluates answers and analyses performance.
6. The system identifies weak concepts.
7. Students receive personalised learning recommendations.
8. Teachers monitor student progress through analytics dashboards.

## ⚙️ Installation & Setup

### Prerequisites
- Node.js and npm
- Python 3.10+
- Git
- Supabase account
- Required AI API credentials

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd LearnSense-AI
```

### 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### 3. Backend Setup

Open another terminal:

```bash
cd backend
python -m venv venv
```

Activate the virtual environment:

**Windows:**
```bash
venv\Scripts\activate
```

**Linux/macOS:**
```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the backend:

```bash
uvicorn main:app --reload
```

### 4. Environment Configuration

Create appropriate environment files and configure your API credentials.

Never commit API keys, passwords, or secret credentials to GitHub.
